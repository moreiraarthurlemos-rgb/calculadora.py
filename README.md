# Calculadora em Python

Calculadora simples feita em Python que realiza as 4 operações básicas: soma, subtração, multiplicação e divisão.

## Como usar
1. Rode o arquivo: `python calculadora.py`
2. Digite os dois números
3. Escolha a operação desejada (1 a 4)
4. Veja o resultado no terminal

## Tecnologias
- Python 3
